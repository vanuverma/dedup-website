Installation Instructions

1

Download the Zipped file

Click the download button above to download the app for your Windows version.

2

Unzip content

Unzip the contents of the downloaded file in your prefered location. Follow the on-screen instructions.

3

Launch the Application

Once unzipped, double-click on the DeDupApp.exe to start the app.

4

Start Organizing

Select your source and destination folders, choose file types, and start organizing your files!

  • Windows Server 2019 or later

⚙️ Hardware

  • Processor: 1 GHz or faster
  • RAM: Minimum 512 MB (2 GB recommended)

📦 Software
