Frequently Asked Questions

Find answers to common questions about DeDup

What is DeDup?

+

DeDup (short form of De-Duplication) is a free, open-source Windows application that helps you organize and copy unique files from source directories to a destination directory. It uses SHA256 hashing to identify truly unique files based on their content, not just file names, ensuring accurate duplicate detection.

Is DeDup really free?

+

Yes! DeDup is completely free and open-source under the MIT License. There are no hidden costs, subscriptions, or premium features. However, if you find it useful, we appreciate donations to support continued development.

What operating systems are supported?

+

DeDup is designed for Windows 10 (version 1809 or later) and Windows 11. We provide builds for 64-bit, 32-bit, and ARM64 architectures. The application requires .NET 8.0 Runtime, which is included in the installer.

Is my data safe? Does the app collect any information?

+

Your data is completely safe. DeDup operates entirely offline with no network access. We do not collect any telemetry, user data, or personal information. All file operations are performed locally on your machine, and no data ever leaves your computer.

How does duplicate detection work?

+

The application uses SHA256 cryptographic hashing to identify unique files. Each file is read and its SHA256 hash is computed. Files with identical hashes are considered duplicates, regardless of their file names. This ensures true content-based duplicate detection, not just filename comparison.

Can I process multiple source folders at once?

+

Yes! Version 2.0 supports adding up to 5 source folders simultaneously. You can add multiple folders, and the application will scan all of them for unique files before copying to the destination folder.

What file types can I organize?

+

By default, the application supports common file types like .doc, .docx, .pdf, .png, .jpg, .jpeg, .txt, .xlsx, and .pptx. However, you can add custom file extensions using the Extension Manager feature. You can also import/export extension lists in XML format.

Can I export the results?

+

Yes! After processing, you can view detailed results and export them to CSV format. The export includes information about successfully copied files, files that already existed in the destination, and any files that failed to copy with error details.

Does it support nested folders?

+

Yes! You can enable the "Include nested folders" option to recursively scan all subfolders within your source directories. This allows you to process entire directory trees in a single operation.

What are the system requirements?

+

Minimum requirements: Windows 10 (1809+) or Windows 11, 1 GHz processor, 512 MB RAM (2 GB recommended), and 100 MB free disk space. The .NET 8.0 Runtime is included in the installer, so no additional software is required.

How much disk space do I need?

+

The application itself requires about 100 MB. However, ensure your destination folder has enough space to accommodate all unique files that will be copied. The application will show an error if the destination runs out of space during copying.

Does it work with network drives?

+

Yes, the application can work with network drives and mapped network locations. However, performance may be slower compared to local drives due to network latency. Ensure you have proper read/write permissions for the network locations.

How fast is the processing?

+

Processing speed depends on several factors: number of files, file sizes, disk speed, and whether you're using hash-based or name-based comparison. The application uses asynchronous processing and is optimized for performance. For faster processing of large file sets, you can enable "Name Based Comparison" in settings.

Can I build it from source?

+

Yes! The source code is available on GitHub. You'll need .NET 8.0 SDK and Visual Studio 2022 (or any compatible IDE). Clone the repository, restore dependencies with dotnet restore, and build with dotnet build --configuration Release.

I'm getting "Access Denied" errors. What should I do?

+

Ensure you have read permissions for the source folders and write permissions for the destination folder. If you're accessing system folders or protected directories, you may need to run the application as administrator (though this is generally not recommended for security reasons).

The application is running slowly. How can I speed it up?

+

Try these solutions: 1) Reduce the number of file types selected, 2) Disable nested folder scanning if not needed, 3) Enable "Name Based Comparison" for faster processing (though less accurate), 4) Process smaller batches of files, 5) Ensure your antivirus isn't scanning every file operation.

Some files aren't being detected as duplicates. Why?

+

The application detects duplicates based on file content (SHA256 hash), not filename. If two files have identical content but different names, they are considered duplicates. If files appear similar but aren't detected as duplicates, they likely have different content (even minor differences will result in different hashes).

The application won't start. What should I do?

+

First, ensure .NET 8.0 Runtime is installed (it should be included with the installer). Try reinstalling the application. Check Windows Event Viewer for error details. If the problem persists, download the portable version or build from source.

Can I cancel a long-running operation?

+

Yes! Click the "Cancel" button during processing to safely stop the operation. The application will stop processing and show results for files processed up to that point. Cancellation is responsive and should stop within a few seconds.

My configuration isn't being saved. What's wrong?

+

Ensure the application has write permissions to %AppData%\UniqueFileOrganizer. This is where configuration files are stored. If you're running from a restricted location or user account, the application may not be able to save settings.
